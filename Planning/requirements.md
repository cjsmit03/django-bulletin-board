# System Requirements

## Functional Requirements

The system must allow users to:

- Register as either a Vendor or Customer.
- Log in and log out securely.
- Recover forgotten passwords using email.
- Vendors must be able to create, edit, view and delete stores.
- Vendors must be able to create, edit, view and delete products.
- Customers must be able to browse products.
- Customers must be able to add products to a shopping cart.
- The shopping cart must be stored using sessions.
- Customers must be able to checkout.
- An invoice must be generated after checkout.
- Customers must be able to leave reviews.
- Reviews should be marked as verified if the customer has purchased the product.

## Non-functional Requirements

- Simple and responsive user interface.
- Secure authentication.
- Data stored in a relational database.
- Easy to maintain and extend.
- Fast page loading.
